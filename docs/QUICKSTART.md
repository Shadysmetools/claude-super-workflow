# ⚡ 60-Second Quick Start

You're one command away from your own AI engineering team. Here's the whole thing.

## 1️⃣ Install (30 seconds)

```bash
claude plugin marketplace add Shadysmetools/claude-super-workflow
claude plugin install super-workflow@claude-super-workflow
```
Restart Claude Code. Done — the team is live.

## 2️⃣ Run it (one command)

```bash
/super-workflow feature "add a dark-mode toggle to settings"
```

Now watch what happens 👇

- 🧑‍✈️ The **tech-lead** wakes up, reads your project, and spins up a team blackboard.
- 🔎 It warms its memory (knowledge graph + past context) so it's not flying blind.
- 🧠 It **shows you a plan and waits for your "go"** — no surprise edits.
- 👥 The right specialists build, review, secure, and QA it.
- 🚦 It ships down the correct pipeline and stops where a human should decide.

You stay the boss's assistant. You approve; the team does the heavy lifting.

## 3️⃣ The only 3 things to remember

| Type this | And you get |
|---|---|
| `/super-workflow bug "<what's broken>"` | A fix, reviewed and gated, ready for prod. |
| `/super-workflow feature "<what to build>"` | A feature, built on staging, QA'd in a browser. |
| `update me` | A 5-second status in plain caveman. ⚡ |

That's it. No config required to start — sensible defaults work out of the box.
